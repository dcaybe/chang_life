# change_life

A new Flutter project.

Dự án phục vụ học tập.

## Hướng dẫn cài đặt và chạy dự án

Đối với các máy chưa cài đặt các thư viện phụ thuộc, bạn cần thực hiện các bước sau để có thể chạy dự án:

1. **Cài đặt các thư viện (dependencies):**
   Mở terminal (hoặc command prompt) tại thư mục gốc của dự án và chạy lệnh sau để tải về toàn bộ các thư viện được khai báo trong `pubspec.yaml`:
   ```bash
   flutter pub get
   ```

2. **Chạy dự án:**
   Sau khi đã cài đặt xong các thư viện, bạn có thể khởi chạy ứng dụng (đảm bảo đã mở máy ảo hoặc kết nối thiết bị thật) bằng lệnh:
   ```bash
   flutter run
   ```

*(Lưu ý: Nếu máy bạn chưa cài đặt môi trường Flutter, vui lòng tham khảo [tài liệu hướng dẫn cài đặt Flutter](https://docs.flutter.dev/get-started/install) trước khi thực hiện các bước trên).*
